# 🗄️ freeCodeCamp: Relational Database Certification
 

A repository with the projects I built during the **Relational Database** certification from [freeCodeCamp](https://www.freecodecamp.org/). It holds the code, scripts, and database dumps for each project, serving as a record of my progress with relational databases.

## 📚 About the certification

The course combines theory and hands-on practice in a Linux environment, focusing on:

- **PostgreSQL**: creating databases and tables, relationships (1:1, 1:N, N:N), primary and foreign keys, constraints (`NOT NULL`, `UNIQUE`), and queries with `JOIN`
- **Bash scripting**: task automation and interacting with the database through `psql`
- **Git and GitHub**: version control for every project
- **Normalization and data modeling**: organizing data and ensuring referential integrity

## 🗂️ Projects

## 🚀 Getting started

Each project lives in its own folder, with a `.sql` file (database dump) and/or `.sh` scripts.

```bash
# Clone the repository
git clone https://github.com/Daniel-Sebastiao/https://github.com/Daniel-Sebastiao/Relational-Database-Certification/
cd your-repo-name

# Restore a project's dump
psql -U postgres < project-name/database.sql
```
